# STATOMERA UI design

Read `docs/BRAND_IDENTITY.md` from the repo root for the active navy, teal, and silver identity. Use shared tokens, the dark default, and an accessible light palette. Preserve the distribution symbol and uppercase STATOMERA wordmark.

Set document language and direction, use logical CSS, isolate original labels and format canonical numbers at render time. Keep responsive tables readable and provide chart equivalents. Check keyboard focus, contrast, mobile layout and localized empty, busy and error states. Use restrained motion.
