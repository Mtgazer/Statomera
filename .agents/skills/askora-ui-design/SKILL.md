# Askora UI design

Read `docs/BRAND_GUIDELINES.md` from the repo root for the approved Electric Graphite palette, Champagne Gold accent and logo concept. Use shared tokens, dark default and an accessible light palette where in scope. Preserve the geometric A, connected graph and lowercase wordmark in approved assets.

Set document language and direction, use logical CSS, isolate original labels and format canonical numbers at render time. Keep responsive tables readable and provide chart equivalents. Check keyboard focus, contrast, mobile layout and localized empty, busy and error states. Use restrained motion.
